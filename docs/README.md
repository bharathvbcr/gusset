# Gusset Documentation Hub

Welcome to the technical documentation for **Gusset**, the production runtime contract for running native Rust engines inside Go services.

Gusset bridges the gap between "FFI bindings exist" and "this runs reliably in production without bringing down the host Go service." It owns the zero-panic firewall, bounded concurrency bulkhead, deadline and cancellation propagation, handle poisoning, ABI layout verification, and allocator accounting.

## Core Invariants Summary

Every subsystem and document in Gusset enforces six non-negotiable invariants:

| Invariant | Name | Guarantee |
| :---: | :--- | :--- |
| **I1** | **Memory Ownership** | Memory is freed exclusively by the allocator that created it via exported `*_free` functions. Go never calls `C.free` on Rust memory. |
| **I2** | **Panic Firewall** | No Rust panic crosses the FFI boundary. A caught panic latches handle poisoning; subsequent calls fail fast with `ErrPoisoned`. |
| **I3** | **Deadline & Cancellation** | Deadlines and cancellations are enforced cooperatively inside Rust between work units using relative `timeout_ns` and per-job `AtomicBool` flags. |
| **I4** | **Bounded Concurrency** | In-flight calls per handle never exceed the configured pool size (capped at 1024). Callers queue in Go, never pinning an OS thread in cgo. Steady-state completions travel over a shared-memory ring. |
| **I5** | **Rust-Owned Stacks** | Heavy Rust work runs on dedicated Rust threads with explicit 8 MiB stacks, protecting against Alpine musl's 128 KiB default. Each worker installs a guard-paged `sigaltstack` (≥ 64 KiB) and blocks SIGPIPE. |
| **I6** | **ABI Layout Verification** | Go `init()` verifies ABI version, struct sizes, alignments, and the offset and size of every named field before serving. |
